About my project:

I have developed an open-source dashboard (github.com/ravidvr/mietspiegel-digitization) that digitizes official German Mietspiegel (rent index) data from city PDFs and makes it publicly accessible as structured, comparable data. The project currently covers 28 German cities, with 23 having complete rent tables, and includes features such as an interactive Leaflet map, cross-city comparison tools, historical trend analysis, and street-level Wohnlage data extracted from official city publications (including Hamburg's Wohnlagenverzeichnis with 25,786 street sections).

The project is strictly non-commercial:
- All data and code are published under CC BY-SA 4.0
- The dashboard is freely accessible to everyone
- No subscription, paywall, or registration is required to view the data
- The project generates no revenue

This would allow the dashboard to show neighborhood-level rent trends across all of Germany, not just the 28 cities currently covered.
