⚙️ Funktionsweise

  1. Abonnieren: Wähle eine Stadt und gib deine E-Mail ein (optional mit Schwellwerten)
  2. Monitoring: Sobald ein neuer Mietspiegel veröffentlicht wird, prüft das System die Werte gegen deine Schwellen
  3. Benachrichtigung: Bei Überschreitung erhältst du eine E-Mail mit den neuen Werten und der prozentualen Änderung
  4. Integration: Deine Abonnements werden lokal gespeichert. Für den Live-E-Mail-Versand wird ein Backend-Dienst (z.B. Mailgun, SendGrid) benötigt — siehe scripts/alert-monitor.py.
