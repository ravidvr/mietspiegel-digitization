📊 Mietspiegel Dashboard

Official German rent index data — digitized, standardized, comparable

I built this because official Mietspiegel (rent index) data exists only as PDFs scattered across 600+ city websites. Nobody had put them all in one place, structured and comparable.

How the data was collected

City PDFs → table extraction → unified schema → interactive map.

Each city publishes its Mietspiegel as a PDF. I download these, extract the rent tables using Python (camelot-py / pdfplumber), and map them to a unified schema that handles different Wohnlage categories, Baujahr periods, and size brackets across cities.

The core table shows the Net Cold Rent (Nettokaltmiete) in €/m² — the legally recognized rent index used for rent increases, Mietspiegelverfahren, and property valuation.

What you can do here

• Browse the map — each circle is a city, colored by average rent

• Compare cities side-by-side — filter by Wohnlage, size, and Baujahr

• Search by city name or Bundesland

• Export the data as CSV for your own analysis

Legal status

Mietspiegel are "amtliche Werke" (§5(2) UrhG) — published by cities in the public interest, free of copyright. Source is cited per city. Data is extracted faithfully, not altered. See individual city pages for the official PDF source.

The result: 17 cities with complete table data so far — from Berlin to Stuttgart, Aachen to München. More cities added regularly.
