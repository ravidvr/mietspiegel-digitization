1. Project Overview

What is a Mietspiegel?

A Mietspiegel (rent index) is an official document published by German cities that establishes the legally admissible rent levels for residential properties. It categorizes rent by:

  • Wohnlage — location quality (einfach/simple, mittel/medium, gut/good)
  • Baujahr — construction year period (from pre-1918 to post-2014)
  • Wohnfläche — apartment size in m²

Each city publishes its Mietspiegel independently — typically as a 30-80 page PDF. No unified national database exists. This project fills that gap.

Why This Matters

Germany's housing market is one of the most regulated in Europe. The Mietspiegel directly affects:

  • Rent control — landlords cannot charge more than the Mietspiegel allows (Mietpreisbremse)
  • Tenant disputes — the official index is admissible in court
  • Policy decisions — cities use the data to justify housing policy
  • Market transparency — comparing official vs actual market rents reveals regulatory gaps

Design Decisions

  • Single HTML file — no npm, no bundler, no framework. The entire dashboard is one self-contained file. This makes it trivial to deploy (just push to GitHub Pages) and inspect (View Source works).
  • Static JSON files — all data is pre-computed and served as static files. No database, no API server, no backend. The browser fetches JSON directly via fetch().
  • Pre-computed aggregation — spatial joins (PLZ, districts), z-score normalization, and city averages are computed offline in Python build scripts. The browser only does nearest-neighbor lookups and rendering.
  • Canvas heatmap — the Immoscout layer uses Leaflet.heat (canvas-based) for performance at 7,304 cells. Radius auto-scales with zoom level (4–20px).

4. Dashboard Features

Unified Map View

  • Always-on heatmap — 7,304 1km² grid cells color-coded by z-score relative to national average. Red = above average (expensive), green = below average (cheap). Radius scales from 20px (country view) to 4px (street view).
  • City text labels — 23 cities shown as subtle text labels with official Mietspiegel average rent. Filterable by state, price range, and construction period.
  • Berlin district overlay — 12 Bezirke appear automatically when zooming into Berlin (zoom ≥ 10). Semi-transparent polygons with color-coded average rent.

Click Interaction

Clicking anywhere on the map performs a nearest-neighbor lookup across all data layers:

  • Finds the nearest RWI grid cell and shows: €/m², year, z-score vs national average, sample size, PLZ, district name
  • If near a city with Mietspiegel data, also shows the official vs market gap (e.g., "Mietspiegel: €11.73 → Market: €10.54 → −10.1%")
  • If inside a Berlin district polygon, shows the district breakdown (einfach/mittel/gut percentages and average rent)

Side Panel

  • Comparison table (always visible) — all 23 cities sorted by Mietspiegel vs Immoscout gap percentage. Each row shows: official rent → market rent → gap with color-coded bar.
  • Detail card (on click) — full Mietspiegel rent table for the selected city with all Wohnlage × Baujahr × Größe combinations.
  • Berlin district card — district-level statistics with einfach/mittel/gut distribution.

Additional Features

  • DE/EN language toggle
  • Dark mode (persisted to localStorage)
  • CSV export of all city data
  • Separate cross-city comparison page with configurable lage/size/baujahr filters
  • Historical trends page
  • Welcome modal on first visit

5. Data Pipeline

Official Mietspiegel Extraction

  1. PDF discovery — search city websites for the latest Mietspiegel brochure PDF
  2. Table extraction — use pdfplumber to extract rent tables (Grundpreis matrix, Zu-/Abschläge, Betriebskosten)
  3. Standardization — normalize to unified schema: city, state, year, type, lage_categories, baujahr_groups, size_categories, source_url, tables array
  4. Validation — spot-check 8+ values against the original PDF, verify rent ranges are plausible
  5. Storage — save as {city_slug}.json in data/processed/

Immoscout Grid Processing

  1. Download — RWI-GEO-REDX PUF v16 ZIP from RWI Essen FDZ
  2. Parse — extract grid-level hedonic indices (redx_grid_rent.json, 1.5 MB, 9,407 grids)
  3. Most-recent-year selection — for each grid cell, pick the latest year with data (2025 preferred, fallback through 2008)
  4. 3σ outlier removal — filter cells beyond 3 standard deviations from mean
  5. Spatial joins — assign each cell to: German district (Kreis), nearest PLZ code (8,299 centroids via KDTree), and city comparison radius
  6. GeoJSON generation — convert grid IDs (ETRS89-LAEA) to WGS84 polygons via pyproj
  7. Output — national-rent-grid.geojson (1.6 MB, 7,304 polygons)

City Comparison

  1. For each of the 23 cities, compute the average Immoscout rent from grid cells within a population-scaled radius (8–25 km)
  2. Compute the Mietspiegel average (mittel Wohnlage, 40–60 m² size range)
  3. Calculate gap percentage: (immoscout_avg − mietspiegel_avg) / mietspiegel_avg × 100
  4. Output: cities_comparison.json

6. Data Quality & Validation

Mietspiegel Data

  • Each city extraction was spot-checked against the original PDF — minimum 8 cross-references per city
  • Values cross-validated against known rent ranges (€4–25/m² for net cold rent in Germany)
  • Baujahr periods normalized to a canonical set of 8 categories for cross-city comparison
  • 5 cities omitted due to PDF unavailability (download blocked by anti-bot measures)

Immoscout Data

  • 375 outlier cells removed (3σ filter) from 23,016 total measurements
  • All values are hedonic quality-adjusted indices — not raw listing prices
  • Sample sizes range from ~30 to ~450 listings per grid cell per year
  • Z-scores computed against cleaned national mean (€7.93/m², σ = €2.83)

Geographic Data

  • District spatial joins: 7,251/7,304 matched (99.3%). 53 cells on borders/coastlines unmatched.
  • PLZ nearest-neighbor: 100% match rate (each cell assigned to closest of 8,299 ZIP centroids)
  • Berlin district polygons: independently validated against 400,505 address-level WFS data points

7. Key Findings

Mietspiegel vs Market Gap

The comparison between official Mietspiegel values and actual Immoscout24 market rents reveals systematic differences:

CityOfficial MietspiegelMarket (Immoscout)Gap
Kiel€7.93€8.32+4.9%
Dresden€7.63€7.82+2.5%
München€19.86€16.86−15.1%
Hamburg€14.52€11.20−22.9%
Köln€14.16€10.58−25.3%
Bremen€11.42€7.64−33.1%

Interpretation: Cities where the market is above the Mietspiegel (positive gap) suggest the official index undervalues the local market — rents are rising faster than regulation captures. Cities with large negative gaps (Bremen, Essen, Köln) likely reflect that the Immoscout grid cells include broader metro areas with cheaper suburbs, while the Mietspiegel is city-proper only.

National Rent Geography

  • Munich orbit: deepest red on the map — €16–25/m² radiating ~40 km from the city center
  • Berlin gradient: sharp east-west divide within the city. Mitte/Prenzlauer Berg at €14–16/m², Marzahn at €8–10/m²
  • Ruhrgebiet: surprisingly uniform yellow-green (€8–12/m²) despite being Germany's largest urban agglomeration
  • Eastern Germany: predominantly green (€4–8/m²) with bright spots around Leipzig, Dresden, and Berlin's commuter belt
  • Rhine corridor: Düsseldorf–Köln–Bonn axis shows a clear rent gradient following the river

9. Limitations & Future Work

Current Limitations

  • 23 of ~80 major German cities — coverage needs to scale 3–4x for comprehensive national representation
  • No municipality-level (Gemeinde) data — the RWI PUF only goes to grid level. The SUF (Scientific Use File) would provide Gemeinde data but requires an academic application
  • Heatmap resolution — at street-level zoom, 1km² cells become individual squares. True address-level data only exists for Berlin.
  • Time lag — Mietspiegel updates every 2 years per city. The dashboard shows the latest available year (2024–2026 range).
  • 5 cities pending extraction — Bielefeld, Chemnitz, Duisburg, Mannheim, Mönchengladbach (PDFs available, removed from dashboard until tables are extracted)

Planned Improvements

  • Batch extract 12 additional cities — 27 PDFs downloaded, district scan pipeline ready
  • Hamburg district layer — Wohnlagenverzeichnis PDF (5.6 MB) parsed for street-level Wohnlage classifications
  • Rent trend visualization — 3,877 grid cells have 3+ years of timeseries data for historical analysis
  • Academic SUF application — for municipality-level RWI data covering all 11,000 German Gemeinden
  • Community contribution pipeline — GitHub issue templates for submitting new city Mietspiegel data

10. Reproducibility

All data processing is fully reproducible:

# Rebuild the national rent GeoJSON from source
cd mietspiegel-digitization
python3 scripts/build_national_choropleth.py

# The script:
# 1. Loads redx_grid_rent.json (1.5 MB, 9,407 grids)
# 2. Applies 3σ outlier removal
# 3. Selects most recent year per grid
# 4. Joins to 434 German districts (STRtree)
# 5. Matches to 8,299 PLZ codes (KDTree)
# 6. Converts LAEA → WGS84 (pyproj)
# 7. Outputs 7,304 polygons → national-rent-grid.geojson (1.6 MB)
