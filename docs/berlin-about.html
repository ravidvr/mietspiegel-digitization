📊 Berlin Rent Map — Documentation

A standalone dashboard showing rent data for every Berlin district, block by block. All statistics use Berlin-local averages. No national data.

Germany's official population and housing census. The Durchschnittliche Nettokaltmiete dataset provides average net cold rent at 100m grid resolution, aggregated to 1km for performance.

Why the census shows lower rents: The census surveys all existing rental contracts, including those signed decades ago at lower rates. Immoscout only shows new listings. The gap between them is the most important insight this dashboard provides.

3. How Calculations Work

3.1 Z-Score (Color Scale)

Every grid cell gets a z-score relative to the Berlin average (not national):

z = (cell_rent - berlin_mean) / berlin_std

This is mapped to a 0–1 intensity for the heatmap gradient. The legend shows ±2σ bands around the Berlin mean (€11.84 for Immoscout, €7.93 for Zensus).

3.2 Market Premium

When you click a location, the tooltip compares the Immoscout value against the nearest Zensus cell:

premium = (immoscout_rent - census_rent) / census_rent × 100

A positive premium means new listings cost more than what existing tenants pay. In central Berlin this is often 50–80%.

3.3 Outlier Removal

Cells beyond 3 standard deviations from the Berlin mean are excluded. This removes ~0.5% of cells with anomalous values (largely grid cells with very low sample sizes at the edges of the bounding box).

4.2 Tech Stack

ComponentTechnology
MapLeaflet.js 1.9.4
HeatmapLeaflet.heat 0.2.0 (canvas)
DataStatic JSON, pre-filtered in Python
DeploymentGitHub Pages
Build toolsPython 3 (pyproj, shapely, scipy)

4.3 Design Decisions

  • Single HTML file, no framework — loads instantly, easy to audit
  • Pre-computed Berlin-only JSON — dashboard never touches national data
  • Full-screen map — no sidebar, maximum data visibility
  • District panel — floating left panel, clickable, auto-populated from GeoJSON
  • Zoom-sensitive heatmap — radius scales from 8 to 18 pixels based on zoom level
  • Dual data toggle — switch between Immoscout (market) and Zensus (census) heatmap with one button

7. Reproducibility

All Berlin data is generated from the national datasets using a bounding box filter. To rebuild:

# Filter Immoscout + Zensus to Berlin, recalculate stats
python3 -c "
import json, math
BERLIN = (52.35, 13.05, 52.65, 13.75)
# ... (see berlin.html source for full logic)
"

The full build pipeline is documented in docs/BERLIN_PLAN.md.
